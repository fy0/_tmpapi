# Account extra 新鲜度

- 配置键由管理员维护并参与调度快照更新；运行态池由网关维护。`openai_cookie_pool` 与现有 turn-state 池同属 scheduler-neutral 键，写入不触发每请求重建调度快照。
- Cookie 注入、探测选取与暂停解除必须从仓储读新鲜池；读失败按空池处理，不能回退到陈旧调度快照复活失败候选。
- 运行态读改写使用账号级互斥，UpdateExtra 仅合并目标键。普通编辑剔除客户端运行态并保留服务器版本；批量编辑和重授权附带 extra 不可写入运行态；换凭据清池。
- 观测以请求开始时间排序，旧请求的迟到响应不能撤销新请求的失败判定。数据库更新在有界上下文中执行，客户端断流不撤销已读到的模型观测。
- 账号级互斥沿用本项目的进程内保护；多实例使用同一 JSONB 顶层键仍可能发生并发覆盖，与现有 state 池一致。
